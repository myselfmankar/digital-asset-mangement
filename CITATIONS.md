# Project Inspirations and Citations

This project is a university-level assignment to build a photo gallery and management application using Python, FastAPI, and a vanilla JavaScript frontend. The goal is to replicate the core functionalities of modern, self-hosted photo management applications.

The user interface, feature set, and overall design of this project are heavily inspired by the following excellent open-source projects. We gratefully acknowledge their contribution to the open-source community and their influence on this work.

## 1. PhotoPrism

*   **Website:** [https://www.photoprism.app/](https://www.photoprism.app/)
*   **GitHub:** [https://github.com/photoprism/photoprism](https://github.com/photoprism/photoprism)
*   **Description:** An AI-Powered Photos App for the Decentralized Web. It is a feature-rich application that supports private cloud deployments and is a benchmark for modern photo management.

## 2. PhotoView

*   **Website:** [https://photoview.github.io/](https://photoview.github.io/)
*   **GitHub:** [https://github.com/photoview/photoview](https://github.com/photoview/photoview)
*   **Description:** A simple and user-friendly photo gallery designed for photographers, aimed at providing an easy way to navigate and view photos stored in a directory structure.

This project aims to mimic some of the core features of these applications, implemented in a Python-based stack for educational purposes.
