**Phase 1: Backend Development (API First)**
*Goal: Implement and test all required API endpoints before starting any frontend work. All database logic will be encapsulated in `api/crud.py`.*

**Step 1.1: Database Model Enhancement (`api/models.py`)**
- [ ] **Modify `Location` model:** Add a new `address` column of type `String` to store the human-readable reverse-geocoded address.

**Step 1.2: Reverse Geocoding Logic (`api/main.py`)**
- [ ] **Integrate Geopy:** In the startup scan logic where EXIF data is processed, add the following steps:
    - [ ] If an image has GPS `latitude` and `longitude`, and its `location.address` is `null`:
        - [ ] Initialize `geopy.Nominatim`.
        - [ ] Call the `reverse()` method with the coordinates.
        - [ ] Store the resulting `address` string in the new `location.address` field in the database.
        - [ ] Add error handling for the API call (e.g., `try...except`).

**Step 1.3: Pydantic Schema Expansion (`api/schemas.py`)**
- [ ] **Modify `Location` schema:** Add the new `address` field.
- [ ] **Modify `Image` schema:** This is the main schema for API output. Ensure it contains all fields required by the UI:
    - `id`, `filename`, `thumbnail_url`, `created_at`, `width`, `height`, `size`, `mimetype`
    - `camera_make`, `camera_model`, `lens_model`, `iso`, `f_number`, `exposure_time`, `focal_length`
    - `is_favorite` (add a boolean field, default to `False` for now)
    - `location: Location` (the nested location object with the new `address` field)

**Step 1.4: CRUD Function Implementation (`api/crud.py`)**
- [ ] **Create `get_album_summary(db)`:**
    - Groups images by year and month.
    - Returns `year`, `month`, `month_name`, `image_count`, and a `preview_image_url` for each group.
- [ ] **Create `get_stats(db)`:**
    - Returns a dictionary containing counts for: `images`, `albums` (unique months), `places` (geotagged images), `favorites`, etc.
- [ ] **Create `get_map_data(db)`:**
    - Returns a list of all images with `latitude`, `longitude`, and `thumbnail_url`.
- [ ] **Update `get_images(db)`:**
    - Ensure this function correctly joins and retrieves all the new data required by the expanded `Image` schema.

**Step 1.5: API Endpoint Implementation (`api/main.py`)**
- [ ] **Create `GET /api/v1/albums/summary`:** Calls the `get_album_summary` CRUD function.
- [ ] **Create `GET /api/v1/stats`:** Calls the `get_stats` CRUD function.
- [ ] **Create `GET /api/v1/map/data`:** Calls the `get_map_data` CRUD function.
- [ ] **Modify `GET /images`:** Ensure it uses the updated `get_images` CRUD function and returns data matching the expanded `Image` schema.

**Step 1.6: HTML Route Modifications (`api/main.py`)**
